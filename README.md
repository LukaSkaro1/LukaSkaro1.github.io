# Luka Skaro — Engineering Portfolio

This is a static HTML portfolio website, based on the supplied two-page PDF portfolio.

## View locally

Open `index.html` in a browser. No build tools or dependencies needed.


## Customize

- Edit `index.html` to modify words, projects and contact information.
- Project photos are in `assets/`.
- Replace `Luka-Skaro-Portfolio.pdf` to update the downloadable PDF.
- Add your LinkedIn, GitHub or resume link to the navigation once ready.

Note: Statements and imagery were drawn from the original PDF; the site does not claim clinical deployment or completed future PCB work.

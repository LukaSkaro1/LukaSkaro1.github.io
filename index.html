PROJECT 01 / BIOMEDICAL OPTICS

Hepatophore™
Optical Biosensor

A sensor prototype designed to detect micromolar concentrations of a biomarker associated with ischemia–reperfusion injury during liver transplantation, helping assess organ viability without bulky laboratory equipment.

↗ Calibration relationship: R ≈ 0.97
What I built
  • Designed and simulated the photodetector → transimpedance amplifier → microcontroller signal chain in LTspice.
  • Tested the live breadboard circuit using biomarker dilutions and biomarker-spiked human plasma.
  • Compared sensor calibration behavior with clinical spectrophotometry measurements.
Next steps

Develop a robust KiCad PCB, add ESP32-based Bluetooth connectivity, and explore integration into a perfusate circuit for live monitoring.

PROJECT 02 / WEARABLE ELECTRONICS

Wearable PPG Sensor

A wearable photoplethysmography (PPG) sensor designed to measure heart rate and blood oxygen saturation (SpO₂), with a custom PCB and controllable optical sensing electronics.

What I built
  • Designed a custom sensor PCB in KiCad and coordinated fabrication with manufacturers.
  • Integrated a PCB → Arduino Nano → Python GUI pipeline to adjust LED colour, intensity, and duty cycle.
  • Demonstrated heart-rate and SpO₂ measurement, with ongoing collaboration for further validation.

PROJECT 03 / DEVICE FABRICATION

Quantum-Dot Curing Vessel

Converted an existing desiccator into a controlled reaction vessel for UV-A curing of polymers containing quantum dots, supporting patterned display-pixel fabrication.

How it works
  • Used SolidWorks thermal FEA to determine heatsink dimensions for the UV-A LED.
  • Introduced an N₂ environment using a fitted inlet to limit unwanted side reactions.
  • Controlled LED intensity and duty cycle using an NMOS transistor and microcontroller.
  • Produced a cured polymer–quantum-dot matrix with defined microwells for display pixels.
